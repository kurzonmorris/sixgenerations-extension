Getting one back

Restoring is a command rather than a button, on purpose — it replaces everything, so it should be a deliberate act at a keyboard:

docker exec sixgenbot python -m sixgenbot restore

That puts back the newest backup, and keeps whatever it replaced beside the database as .beforeRestore. Add --file to choose a different one.

Offsite

Point pCloud Drive or rclone at the backup folder above. sixgenbot never holds a pCloud password — one fewer secret to lose.
